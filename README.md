# Maria Pe website

Portfolio and services site for Maria Pe, Freelance Web & Content Consultant.

Plain HTML, CSS and a little JavaScript. No build step.

## Publish on GitHub Pages
1. Settings > Pages
2. Source: Deploy from a branch
3. Branch: main, folder: / (root). Save.
4. The site goes live at https://<username>.github.io/<repo-name>/ in a minute or two.

## Edit
Change any .html file, commit, push. Pages updates on its own.
